# Age cohorts

P15. The strategy is defined over a token-age window. Whether that window is the
right one is an empirical question, and it cannot be answered by a corpus that
only contains tokens inside it.

Generated by `pnpm cohort:status` into `artifacts/cohort-status.json`.

The NULL rows stop at 15:42 and the assigned rows begin at 15:45. Cohort
assignment has run on every shadow opened since the feature landed. They are
marked `cohort_source = 'PREDATES_FEATURE'` rather than left ambiguous.

### Why they are not backfilled

The obvious repair is to match each old position to the nearest decision
snapshot by mint and time and derive an age from it. `decision_snapshots`
records `token_age_ms`, so the number is there.

That would be inference, not re-derivation. **Nothing links a shadow position to
the snapshot that produced it** — no snapshot id on the position, none on the
observation — so the join would be a guess about which screening was probably
the one. A cohort assigned that way is indistinguishable from a measured one and
is not measured, which is the exact error the rest of this corpus was rebuilt to
remove.

So they stay NULL, and `cohort_source` says why.

### The real limitation

The usable sample is **118 shadows in a single arm**. That is not a small
comparison; it is no comparison. Reporting a cohort effect from one arm would be
reporting the only arm that exists.

## Why cohorts at all

The gates admit tokens between 2 and 60 minutes old. Every observation the
system keeps is therefore about that window, and the window's own edges are
invisible: if the real edge lives at 90 minutes, nothing in the corpus can say
so, and every analysis will conclude that 2-60 minutes is where the edge is
because it is where the data is.

Shadow books are the instrument for this. They cost no capital, so they can
carry arms the portfolio would never take.

## Arms

```
AGE_0M_2M     below the minimum age gate
AGE_2M_60M    the current eligible window
AGE_60M_6H    above the maximum age gate
AGE_6H_PLUS   well past it
```

The 2-60 arm is the control. It is the one the portfolio actually trades, so it
is the one every other arm is measured against.

## What must be true before a cohort result means anything

1. **Assignment at open, from the observed age**, never backfilled. A cohort
   assigned after the outcome is known is not an assignment.
2. **The same evidence class across arms.** Comparing an effect-verified arm to
   a structural one measures the simulator, not the age.
3. **The same size in every arm.** The books are frozen per book for this
   reason: a result that varies with notional is not a result about age.
4. **Enough closed positions per arm** to distinguish the arms from noise. One
   arm with 114 rows and three with none is not a comparison.
5. **Preregistration.** The arms and the comparison go in
   `docs/MULTIPLE_TESTING_LEDGER.csv` before the numbers are looked at.
   Choosing which cohort split to report after seeing four is spending alpha
   four times and reporting it once.

None of the five currently holds.

## What is actually open

Not the assignment — that runs. The open items are:

1. **Only one arm has data.** `AGE_2M_60M` is the eligible window and the only
   arm the portfolio would ever trade, so it is the only one the shadow books
   have opened into. The out-of-window arms need shadows opened deliberately,
   which is a change to what the books admit, not to the assignment.
2. **118 positions is too few** to distinguish any arm from noise.
3. **No arm has an evidence class above `STRUCTURAL_ONLY`**, so even a
   between-arm difference would be a difference between two sets of unverified
   simulations.

No threshold may be moved on the strength of this experiment, and none has
been.
